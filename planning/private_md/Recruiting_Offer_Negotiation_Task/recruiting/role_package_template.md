# Compensation Package Framework — Backend Software Engineer, Mid-Level

Shared reference for this negotiation (both parties may read this — it
defines the structure and outer limits any offer must fit within; it does
NOT reveal either party's actual private position within those limits).

## Posted range
- Base salary: $90,000 – $120,000/year (publicly posted with the role).

## Additional levers available (separate from base salary budget)
- **Signing bonus**: a one-time payment, $0 – $15,000, drawn from a
  separate hiring budget line, not the role's ongoing base salary budget.
- **Equity grant**: 0% – 0.08% of company shares, vesting over 4 years,
  drawn from the equity pool, not the base salary budget.

## Norms for this negotiation
- An offer or counter-offer should be stated as a full package (base +
  signing bonus + equity, using $0/0% for any lever not being offered),
  not just a bare base salary number, once either side moves beyond an
  opening anchor.
- Base salary, signing bonus, and equity draw from three separate budget
  lines — a party unable to move further on one lever may still have real
  room on another. Do not assume a stalled base-salary negotiation means
  the whole negotiation is stalled.
